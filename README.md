# Business Portfolio Website

## Project Overview
A responsive business portfolio website developed using PHP, MySQL, HTML, CSS, and JavaScript.

The website presents the company's information, services, portfolio projects, frequently asked questions, and contact details.

## Features
- Dynamic content retrieved from a MySQL database.
- Home, About, Services, and Contact sections.
- Services management page.
- Portfolio projects and FAQ sections.
- Responsive layout for different screen sizes.

## Technologies Used
- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- XAMPP
- phpMyAdmin

## Installation and Setup
1. Install XAMPP.
2. Copy the project folder into `C:\xampp\htdocs\business-portfolio`.
3. Start Apache and MySQL from the XAMPP Control Panel.
4. Open phpMyAdmin at `http://localhost/phpmyadmin`.
5. Create a database named `business_portfolio_db`.
6. Import the project's database SQL file.
7. Open `http://localhost/business-portfolio/` in your browser.
